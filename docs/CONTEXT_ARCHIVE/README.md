## Exactly what this archive does NOT claim

This is not a complete export of the user's historical ChatGPT account or all project chat conversations. Only conversation excerpts made visible to this session, and the text the user uploaded, were available. It does not prove any app, CI or video tests have run; main was documentation-only at snapshot time. The research PRs are not accepted architecture or license approvals.

For secure continuity, **never upload credentials, private meeting recordings, user data or provider API keys** here. To preserve additional missing chats, export them and archive plain-text copies with dates and provenance.
